# PaOS Forge™ website forwarding

This small repository keeps the original `paosforge.com` GitHub Pages address working while the public [PaOS Forge website](https://paosforge.com/) moves to Netlify. It is **not** the operating system source repository.

PaOS Forge is a personal operating system in development, combining a native desktop with planned modular Linux capabilities, local tools, automation, and AI. You can [explore the beta desktop simulator](https://gransee.com/review/paos-8bc176296315f468b1089ab1/) now; it is a browser design preview, best on a laptop or desktop.

**Public OS source, installers, hardware guidance, and contribution instructions are coming soon.** Visit the [organization introduction](https://github.com/paosforge) for the current status.
